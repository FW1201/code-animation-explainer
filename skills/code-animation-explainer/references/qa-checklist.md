# 驗收清單（每幕與全片）

## 每幕（寫完就截圖檢查，至少取 3 個時間點：開頭、中段、結尾前）
- [ ] 文字沒有溢出卡片或畫面；中文沒有變成方框（字型有載入）
- [ ] 元素對齊網格，沒有非刻意的重疊
- [ ] 截圖卡、圖示沒有壓到字幕區（底部 180px）
- [ ] 動畫出現時機對上旁白關鍵字（用 AT 錨點）
- [ ] 上一個階段的元素已淡出，沒有殘影
- [ ] 截圖都有來源標示

## 全片
- [ ] 引擎檢查零錯誤（HyperFrames：`npx hyperframes check`，含版面與 WCAG 對比度）
- [ ] 轉場色塊完全離開畫面、沒有殘留
- [ ] 字幕沒有孤字換行、沒有閃爍、關鍵詞高亮時機正確
- [ ] 渲染後 `ffprobe`：片長、1920×1080、30fps、有 AAC 音軌
- [ ] `ffmpeg -af silencedetect=noise=-40dB:d=2` 沒有意外長靜音
- [ ] `ffmpeg -af volumedetect`：max 不超過約 -1 dB（不破音），背景音樂明顯低於人聲
- [ ] 片尾出處頁與說明欄出處一致；TTS 服務要求的標註已加上

## 常見錯誤與修法
| 症狀 | 原因 | 修法 |
|---|---|---|
| 某段畫面空白 | 階段切換太快，被下一階段覆蓋 | 把示範拉到旁白真正描述它的句子 |
| 色塊停在畫面邊 | 位移距離不足（斜切＋寬度） | xPercent 拉到 ±190 |
| 一次寫入大檔失敗 | 平台單次寫入逾時 | 拆成 .css/.html/.js 與 .b/.c 小檔 |
| 字幕最後一行只有一個字 | 寬度剛好卡住 | `text-wrap: balance` |
| 動畫和聲音對不上 | 寫死秒數 | 改用 AT("關鍵字") 並重新建置 |
