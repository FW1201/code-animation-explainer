# 剪紙／皮影戲風格指南

> 參數以風格卡 `assets/styles/puppet-shadow.json` 為準（`python scripts/style_apply.py puppet-shadow --out style/`）；本文件補充舞台結構、人物元件與關節工具。

適合歷史、典故、民俗、節慶類內容。觀眾一眼就知道「在講故事」，而且全部用 SVG 程式繪製，沒有素材授權問題。範例：教師節〈孔子向師襄學琴〉。

## 舞台（主合成固定不動）
- **木框＋背光幕布**：外圈深色木框，中間暖黃幕布（徑向漸層，中心亮、邊緣暗），模擬燈從後面打過來。
- **燈光轉場**：幕與幕之間用「燈暗 → 換景 → 燈亮」（整個幕布亮度 1 → 0.15 → 1，約 0.8 秒），取代 Vox 的色塊掃過。
- 字幕放在幕布下緣的木框上，像戲台字幕。

## 皮影人物（元件化）
- 用彩色**半透明**填色（opacity 約 0.9）＋鏤空紋樣（SVG pattern 疊在 clipPath 內）＋深色粗描邊，才有皮影透光的質感。
- 每個人物是固定結構，方便所有幕共用：
  ```
  <g id="pid">                ← 外層：只負責定位（transform 寫在這裡，GSAP 不碰）
    <g id="pid-m">            ← GSAP 位移、淡入淡出
      pid-sway / pid-arm / pid-head   ← 關節：attr transform="rotate(角度 軸x 軸y)"，軸心存在 data-p
  ```
- 關節動作小工具（放在每幕共用的 JS 裡）：
  - `J(選擇器, 角度, 秒數, 時間點)`：轉動關節到指定角度
  - `WIG(選擇器, 角度A, 角度B, 週期, 開始, 結束)`：有限次來回擺動（點頭、彈琴、揮手），結束時回正
  - `POP`／`OUT`／`INK`：道具彈出、淡出、文字像墨跡一樣逐字浮現
- 人物朝向用鏡像參數（flip），不要另外畫一套。
- 元件庫寫成程式（例：Python 函式回傳 SVG 字串：站立人物、跪坐、古琴、窗花、對話框），markup 用 `{{ person(...) }}` 在建置時展開；紋樣與濾鏡 id 用「§」佔位，建置時換成各幕前綴，避免重複。

## 動作原則
- 皮影的動作是「關節轉動＋整身平移」，不要做真實人體的彎曲或變形。
- 說話的人：頭部小幅點動（±4°）；彈琴、寫字：前臂週期擺動；走路：整身上下起伏＋平移。
- 所有擺動都要有限次數並在結束時回正，才能任意 seek、每次渲染結果一樣。

## 配音與音樂
- 旁白用沉穩的說書聲音（例：ElevenLabs Bill，約 2.7 字／秒），每幕前後留白拉長（0.6／0.9 秒）。
- 背景音樂用 `scripts/bgm_qin.py`：五聲音階（宮商角徵羽）撥弦琴音＋低音持續音，固定亂數種子可重現，沒有授權問題。

## 常見問題
| 症狀 | 原因 | 修法 |
|---|---|---|
| 人物一動就跑到畫面角落 | GSAP 動的 `<g>` 同時有 transform 屬性 | 外層 g 定位、內層 g 給 GSAP |
| 手臂繞錯點旋轉 | 用了 px 的 transformOrigin | 關節用 attr rotate＋data-p 軸心；縮放用 svgOrigin |
| 不同幕的紋樣互相覆蓋 | pattern／filter id 重複 | id 用 § 前綴，建置時替換 |
