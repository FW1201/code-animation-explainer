# Vox 解說風格設計指南

> 參數以風格卡 `assets/styles/vox-paper.json` 為準（`python scripts/style_apply.py vox-paper --out style/`）；本文件補充設計理由與元素做法。

為什麼選這個風格：真實截圖提供可信度，螢光筆、紅圈與鏡頭推近把視線帶到重點，抽象概念因此能「指著講」。

## 視覺元素
- **紙張底**：米白 `#F2ECDF`＋SVG `feTurbulence` 雜訊顆粒＋淡暈影。
- **截圖卡**：白邊（padding 12px）、柔和陰影、輕微旋轉 ±2°、上方一條半透明膠帶；下方小字「來源：網域」。
- **螢光筆**：文字後方一條半高色帶，用 `scaleX 0→1`（transform-origin 左）畫出。
- **紅圈／叉叉**：SVG path 設 `pathLength="1" stroke-dasharray="1" stroke-dashoffset="1"`，動畫到 0 即「手繪」。
- **扁平卡片**：3px 深色邊框＋8px 實心位移陰影，像剪紙。
- **程式碼卡**：深色 `#0D1117` 底、等寬字，和紙張底形成對比；逐行淡入。
- **鏡頭推近**：對截圖做緩慢 scale 1→1.08（Ken Burns）。
- **轉場**：斜切色塊掃過（三色輪替）。

## 版面
- 1920×1080：左右安全邊界 96px；上方 60–140px 放幕別標籤（例：`01 選對模型`）；底部 180px 留給字幕。
- 一次只講一件事：每個「階段」一個焦點元素，換階段時舊元素淡出。
- 每 3–5 秒要有一個視覺變化，對上旁白的關鍵字。

## 配色（見風格卡）
紙 `#F2ECDF`、墨 `#1E1B18`、主色青 `#0A7A96`（紙底上對比 4.2:1，可當大字與圖形）、紅筆橘 `#C2410C`、紫 `#6D28D9`、螢光黃 `#FFD84D`。要換成品牌色：`style_apply.py vox-paper --set color.primary=#xxxxxx`，並看它列出的對比度。

## 字型
標題用襯線（Noto Serif TC 900），內文 Noto Sans TC，程式碼 JetBrains Mono，皆為 OFL 授權。

## 真實素材的優先順序
1. 你自己操作的畫面：本片的原始碼、預覽截圖、修正前後對比、真實配音波形、真實字級時間戳
2. 官方文件與產品頁截圖（標註來源與擷取日期）
3. 開放授權圖示與插圖
