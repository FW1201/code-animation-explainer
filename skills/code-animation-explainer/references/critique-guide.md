# 教學動畫評審

使用者說「評審」「打分數」「好不好」「幫我看看」，或你交付前想自己檢查一次時使用。**評作品，不評人。**

## 6 個維度（各 0–10 分）

| # | 維度 | 權重 | 看什麼 | 低分的典型樣子 |
|---|---|---|---|---|
| 0 | **教學概念清晰度** | ×2 | 看完能用一句話說出學到什麼嗎？動畫動作有在解釋概念，還是只是裝飾？ | 畫面很漂亮，但學生說不出重點 |
| 1 | 教學結構 | ×1 | 引起動機 → 建立概念 → 例證 → 統整；有呼吸字卡；多案例有地圖 | 一路平鋪直敘，沒有高低起伏 |
| 2 | 風格一致性 | ×1 | 所有幕都用同一張風格卡；顏色照語意；有招牌動作；`style_lint` 零錯誤 | 第 1 幕 Vox、第 5 幕變成通用簡報 |
| 3 | 視覺層級 | ×1 | 每幀 ≤3 個活躍元素；焦點明確；字級層級清楚；3 公尺測試過關 | 一幀塞五張卡，視線不知道看哪 |
| 4 | 動態節奏 | ×1 | hero 貫穿；換幕不硬切；easing 有重量；關鍵處有停留；運鏡在預算內 | 每個元素都淡入上移、同一個速度 |
| 5 | 音畫同步與細節 | ×1 | 動作卡在旁白關鍵字；字幕不閃不孤字；讀音正確；元素不溢出容器 | 箭頭出現時旁白已經講到下一句 |

總分＝（維度 0 ×2＋其他五項）÷ 7，取一位小數。8 分以上可交付；6–8 分修完 Fix 清單再交；6 分以下回到分鏡或方向板。

## 輸出格式

```markdown
## 評審：〈影片名〉　總分 7.4／10

| 維度 | 分數 | 一句話 |
|---|---|---|
| 教學概念清晰度 | 8 | 箭頭射出很直觀地說明「對」的方向性 |
| …

### 做得好（Keep）
- 第 2 幕「對」的箭頭動作讓方向性一眼就懂——保留，並用在第 4 幕的「給」

### 要修（Fix）
- ⚠️ 致命　第 3 幕 0:52 字幕壓到圖表最下面一列
- ⚡ 重要　第 4 幕換幕是整頁淡出，改成「給」字從角落移到中央（共享元素）
- 💡 優化　統整幕停留只有 1.2 秒，拉到 2 秒

### 5 分鐘內能做的前三件事（Quick Wins）
1. …
```

每一條 Fix 都要寫**時間點＋具體改法**，不要寫「可以再精緻一點」。

## 常見問題前十名

1. 像帶配音的簡報（每幕獨立、整頁淡入淡出）→ `motion-language.md` §1
2. 風格中途漂移（顏色、字型、easing 被寫死）→ `style_lint.py`
3. 一幀元素太多 → 規則 1：≤3 個活躍元素
4. 字太小，教室後排看不到 → 字級不低於風格卡 `body`
5. 顏色太多、沒有語意 → 只用風格卡 8 色並照 `color_semantics`
6. 裝飾大於內容（每個標題配圖示、emoji）→ `style-system.md` §5
7. 圖上的數字沒出處 → `review-gates.md` 關卡 1
8. 動畫順序和概念邏輯相反（樹狀圖先撒點再連線）
9. 鏡頭動太多、推近沒有錨點 → 運鏡預算
10. 結尾淡出到黑、沒有停住 → 回全景停 ≥0.8 秒
