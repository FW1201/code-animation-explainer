# 8 參數提示詞框架

給模型寫動畫程式時（包括你自己要寫下一幕時），把這 8 個參數寫清楚。每一個參數都對應一種常見失敗。

| # | 參數 | 寫什麼 | 沒寫會怎樣 |
|---|---|---|---|
| 1 | 角色與觀眾 | 誰看、語氣、深度 | 用語太難或太幼稚 |
| 2 | 成品規格 | 解析度、fps、總秒數、輸出格式 | 尺寸怪、長度失控 |
| 3 | 設計系統 | 色票 hex、字型與字級、間距、安全邊界 | 每幕風格不一致 |
| 4 | 分鏡 JSON | 先輸出 storyboard.json，確認後才寫程式 | 結構每次不同 |
| 5 | 動畫語彙 | **風格名稱＋渲染技術＋動作行為＋互動方式**；進出場秒數與 easing、錯開間隔、轉場、節奏 | 動作生硬或亂飛、風格不明 |
| 6 | 技術約束 | 指定引擎；禁用隨機數／即時時間；時間軸驅動 | 每次渲染不同、無法迭代 |
| 7 | 素材規則 | 來源、授權、截圖尺寸、出處標註 | 版權風險、素材模糊 |
| 8 | 驗收標準 | 每幕截圖檢查溢字、對齊、中文字型、字幕遮擋 | 錯誤留到最後才發現 |

## 可直接複製的模板

```
① 角色與觀眾
你是教學動畫導演。觀眾是＿＿，語氣＿＿，深度＿＿。

② 成品規格
1920×1080、30fps、總長＿＿秒、輸出 MP4。

③ 設計系統
背景＿＿、主色＿＿、強調色＿＿；字型＿＿（標題 72px／內文 40px）；安全邊界 96px；底部 180px 保留給字幕。

④ 分鏡（先輸出 storyboard.json，我確認後再寫程式）
每幕欄位：id、narration、visual_intent、duration_sec、transition_in。

⑤ 動畫語彙
風格：＿＿（例：Animated Diagram，見 animation-styles.md）；技術：＿＿（例：SVG＋GSAP）；動作：＿＿（例：sequential reveal、path drawing）；互動：＿＿（影片版可寫「無」）。
進場 0.6s ease-out、退場 0.4s ease-in；元素錯開 0.08s；每 3–5 秒一個視覺變化。

⑥ 技術約束
使用＿＿（HyperFrames / Remotion / Manim / HTML+GSAP）；禁止 Math.random() 與 Date.now()；所有動畫由暫停的時間軸驅動，渲染結果可重現。

⑦ 素材規則
只用開放授權素材並標註來源；網頁截圖以 1600–1920 寬擷取；記錄擷取日期。

⑧ 驗收標準
每完成一幕就渲染截圖並自我檢查：文字不溢出、元素對齊、中文無方框字、字幕不遮擋主體。有問題先修正再往下。
```

**原則：形容詞不如數字。**「動畫要流暢一點」→「0.6 秒、ease-out」；「字大一點」→「標題 84px」。
