# 字幕與音畫同步

## 時間戳從哪來
| 來源 | 精度 | 何時用 |
|---|---|---|
| ElevenLabs API `/with-timestamps`（`tts_elevenlabs.py`） | 每個字 | API key 路線；首選 |
| `align_audio.py --asr`（離線 SenseVoice 逐字時間，誤差約 0.05 秒） | 每個字 | 連接器路線、自己錄音、或音檔用 atempo 放慢過 |
| `align_audio.py`（靜音偵測＋字數比例） | 片段到字 | 沒裝 sherpa-onnx 時的備案；語速快、停頓少時會對歪 |

時間戳只拿「時間」，字幕文字一律用 `narration`（即使配音送的是 `tts` 同音字）。
**讀音檢核不用 Whisper／scribe**：它們會把唸錯的音「猜回」正確的字。用 `pron_check.py`（見 `voice-tts.md`）。

## 斷句規則（`scripts/build_captions.py` 實作）
- 字幕文字以**腳本原文**為準，移除 `[pause]` 等標籤；辨識結果只拿時間。
- 在 。！？ 一定斷；在 ，：；、 且累積 ≥ 11 字時斷；單則最多約 30 字。
- 每行建議約 16 個中文字、上限 22 字（`read_check.py --line 22` 檢查）、最多 2 行；CSS 用 `text-wrap: balance` 避免最後一行只剩一個字。
- 句尾逗號句號不顯示；相鄰字幕間隔 < 0.6 秒就接起來，避免閃爍。
- 開始＝第一個字的開始時間；結束＝最後一個字結束 +0.6 秒（不超過下一句開始）。下一句 1.8 秒內就來的半句，會和下一句併成兩行（合計 ≤ 30 字）。

## 讓動畫卡在語音上
在場景程式裡用錨點而不是寫死秒數：
```js
tl.fromTo("#card-opus", {opacity:0}, {opacity:1, duration:0.5}, AT("Opus"));
```
建置時把錨點換成秒數（加上場景前導留白）：
- `AT("字串")`：全片旁白中第一次出現的位置。
- `AT("s3", "字串")`：只在 s3 這一幕找（同一個詞在多幕出現時用這個）。

配音重錄後重新建置，動畫自動跟上；**但改寫旁白後，關鍵字可能不見了**——跑 `sync_check.py` 確認每個錨點的字串都還在旁白裡。

## 樣式建議
- 底部置中、深色半透明底條、白字粗體 44px（1080p）。
- 關鍵詞唸到時變主色；英文術語在字幕上方加小字註解（例：韻律＝prosody）。
- 另外輸出 `.srt` 讓平台可開關字幕。
