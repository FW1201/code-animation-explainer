# 字幕與音畫同步

## 時間戳從哪來
| 來源 | 精度 | 說明 |
|---|---|---|
| TTS 回傳的字級對齊（ElevenLabs `/with-timestamps`） | 每個字 | 最準；文字就是腳本原文。首選 |
| Whisper／WhisperX／Parakeet 轉寫 | 英文到字、中文常只到句 | 真人錄音時用；中文建議搭配強制對齊（forced alignment） |
| 手動估算（字數 ÷ 語速） | 粗略 | 最後手段 |

Whisper 是 STT（聲音→文字），在這條產線的角色是「對齊與核對」，不是配音。用它轉寫一段配音，可以順便檢查 TTS 有沒有唸錯字。

## 斷句規則（`scripts/build_captions.py` 實作）
- 字幕文字以**腳本原文**為準，移除 `[pause]` 等標籤；辨識結果只拿時間。
- 在 。！？ 一定斷；在 ，：；、 且累積 ≥ 11 字時斷；單則最多約 30 字。
- 每行約 16 個中文字、最多 2 行；CSS 用 `text-wrap: balance` 避免最後一行只剩一個字。
- 句尾逗號句號不顯示；相鄰字幕間隔 < 0.6 秒就接起來，避免閃爍。
- 開始＝第一個字的開始時間；結束＝最後一個字結束 +0.35 秒（不超過下一句開始）。

## 讓動畫卡在語音上
在場景程式裡用錨點而不是寫死秒數：
```js
tl.fromTo("#card-opus", {opacity:0}, {opacity:1, duration:0.5}, AT("Opus"));
```
建置時把 `AT("字串")` 換成該字串在配音中第一次出現的秒數（加上場景前導留白）。配音重錄後重新建置，動畫自動跟上。

## 樣式建議
- 底部置中、深色半透明底條、白字粗體 44px（1080p）。
- 關鍵詞唸到時變主色；英文術語在字幕上方加小字註解（例：韻律＝prosody）。
- 另外輸出 `.srt` 讓平台可開關字幕。
