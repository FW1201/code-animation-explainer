# 動態語言：不要做成「帶配音的 PowerPoint」

時長與 easing 的**數值**來自風格卡（`M.in()` 等，見 `style-system.md`）；這份文件管**怎麼動才像一支片，而不是一頁頁投影片**。

## 1. 鐵律（寫任何一行時間軸之前）

**失敗模式第一名**：每幕獨立排版 → 每個重點都淡入上移 → 換幕時整頁淡出淡入。觀眾的第一反應是「這是有配音的簡報」。

1. **整支片是一段連續的運動，不是一疊獨立畫面。**選 1–2 個 **hero element**（主角元素）從開頭存在到結尾，每一幕是它的狀態改變（位置、大小、顏色、形態），而不是換一個新東西。
   - 講介詞「跟／對／給」：hero＝三個介詞字。開場並排 → 「對」放大射出箭頭、其他兩個退到角落 → 換「給」上場 → 結尾三個字回到中央、各自帶著學到的箭頭樣式。
   - 講光合作用：hero＝一片葉子。從全景推近到葉綠體，再拉回整株植物。
   - 把 hero 寫進 `storyboard.json` 的 `hero_elements`，每幕寫它的狀態（`hero_state`）。
2. **幕與幕之間不硬切**：上一幕的元素**變形成**下一幕的主角（共享元素），或用風格卡指定的轉場（`storyboard-craft.md` §5）。整頁 opacity 1→0、下一頁 0→1 只能當最後手段。
3. **任一幀都有運動**：隨便暫停在非重點時刻，畫面也不該完全靜止。至少有一個底層運動在跑：hero 呼吸（scale 1↔1.02、5 秒週期）、背景極慢漂移、截圖 Ken Burns。用風格卡的 `motion.idle`。**運動要有限次數**（`repeat` 寫死次數，不用 −1），才能任意 seek。
4. **easing、錯開、停留是底線**：不用 linear 與 CSS 預設 ease；多個元素進場錯開 `M.stagger`；關鍵結果出現前先停 `M.hold`（0.5 秒左右）；結尾停住，不淡出到黑。

**自我檢查**：給沒看過的人看（或自己隔天看），第一反應是什麼？「像簡報」＝重做；「畫面跟著聲音在換」＝hero 沒貫穿；「這段我想截圖」＝做到了。

## 2. 教學動畫的運動語法

| 原則 | 做法 | 為什麼 |
|---|---|---|
| 展示過程，不展示魔法結果 | 例：分數相加，要看到兩塊披薩切成同樣大小再合起來，不是答案直接跳出來 | 學生學的是過程 |
| 一幕一個關鍵動效 | 其他元素只做進出場 | 注意力只有一份 |
| 動作有預備與餘韻 | 彈出前先縮一點（anticipation），落定時微微過衝再回正 | 有重量感，不像幻燈片 |
| 焦點切換＝背景變暗＋變模糊＋主體變清楚 | `filter: blur(4px) brightness(.6)` 給退場元素，不是只降透明度 | 視線被帶過去 |
| 關鍵結果前停一下 | 前一段先靜止 0.3–0.5 秒，再揭曉 | 學生有時間預測答案 |
| 動畫順序符合概念邏輯 | 階層由上而下長出；流程依步驟；因果先因後果；比較先並列再標差異 | 動作本身就在教 |
| 同一個概念同一種動作 | 例：所有「方向」都用箭頭射出、所有「合併」都用靠攏 | 動作也是符號系統 |

## 3. 運鏡預算（鏡頭動越少越準越好）

| 項目 | 預算 |
|---|---|
| 相鄰兩次鏡頭變化間隔 | ≥ 3 秒（克制風格 ≥ 5 秒） |
| 任意 15 秒內鏡頭變化 | ≤ 4 次（各風格卡的 `camera.budget` 更嚴就依卡） |
| 推近倍率 | 1.25x 以上才推（低於這個像晃動）；上限依風格卡 `camera.max_zoom`，再高就換高解析素材 |
| 開場 | 1.06x 定場微推，3 秒內回到 1x，讓畫面一開始就是活的 |
| 結尾 | 回到全景，停 ≥ 0.8 秒；不要停在推近狀態 |
| 推拉時長 | `M.zoomDur(from, to)`：依倍率變化量，1→2x 約 0.55 秒，介於 0.30–0.94 秒 |
| 相鄰兩個焦點 | 很近就合成一鏡；中等距離就平移過去（不要拉出再推進）；很遠就刪掉一鏡 |
| 節奏偏好 | **寧慢勿快**：拿不準時長選長的，拿不準要不要動鏡選不動 |

推近的終點必須是一個說得出名字的東西（那個字、那個數字、那個按鈕）。

## 4. 逐格渲染的安全規則（HyperFrames／GSAP）

| 陷阱 | 症狀 | 修法 |
|---|---|---|
| `fromTo()`／`from()` 的 immediateRender | 元素在它的動畫開始前好幾秒就出現在畫面上 | 一律 `gsap.set()` 先設初始狀態，再用 `to()`；非用 fromTo 不可時加 `immediateRender:false` 並確認初始不可見 |
| CSS transition＋切換 class | seek 渲染時狀態不確定 | 全部改成 GSAP 補間（`style_lint.py` 會警告） |
| 代理補間在 t=0 不觸發 onUpdate | 第一幀是空的 | 註冊時間軸後手動呼叫一次 render(0) |
| `transform: scale()` 推近文字 | 放大後字變糊 | 鏡頭層用 CSS `zoom` 放大（重新排版、重新點陣化），只用在最外層相機容器 |
| 平移露邊 | 鏡頭一動就看到畫布外的空白 | 世界層四周多留 ≥ 最大平移量＋8% 的出血 |
| 3D 突然變平 | perspective 失效 | 相機到 3D 元素之間的中間層不能有 overflow:hidden、filter、opacity<1、clip-path |
| 亂數、系統時間 | 每次渲染結果不同 | 固定種子 PRNG；時間一律從時間軸 t 計算 |
| 無限重複 | 無法 seek、渲染卡住 | `repeat` 寫固定次數 |

鏡頭層結構：
```html
<div class="stage …">          <!-- 固定 1920×1080，不動 -->
  <div id="cam">               <!-- 只做 zoom 與 translate（鏡頭） -->
    <div id="world">…</div>    <!-- 內容；四周留出血 -->
  </div>
  <div class="caption-bar">…</div>  <!-- 字幕在鏡頭外，不跟著放大 -->
</div>
```

## 5. 交付前 60 秒自檢

- [ ] 有 hero element 從頭貫穿到尾，`storyboard.json` 每幕都寫了 `hero_state`
- [ ] 隨便暫停三個非重點時刻，畫面都有在動
- [ ] 沒有整頁淡出淡入的換幕；每個接縫都用了風格卡的轉場或共享元素
- [ ] 每幕至少用了一個風格卡的招牌動作
- [ ] 關鍵結果前有停留；結尾停住、回全景
- [ ] 任意 15 秒鏡頭變化不超過預算；推近都有具體錨點
- [ ] `style_lint.py` 零錯誤（easing、時長都來自風格卡）
