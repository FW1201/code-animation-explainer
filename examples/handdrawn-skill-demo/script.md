# 用 AI 做手寫風教學動畫——這套 skill 怎麼幫你

> 約 90 秒｜sketch-board（手繪草圖，Excalidraw 式）｜旁白以 `storyboard.json` 的 `narration` 為準

| 幕 | 旁白 | 〔畫面〕 |
|---|---|---|
| s0 | 叫 AI 做一支手繪風的教學動畫，第一幕很像手畫的，到了第五幕，卻變回了簡報。 | 第 1 幕手繪縮圖 vs 第 5 幕簡報縮圖，紅圈圈起第 5 幕 |
| s1 | 因為「手繪風」只是一個形容詞。模型每畫一幕，就重新猜一次。 | 「手繪風」射出五個箭頭，連到五種長相不同的塗鴉 |
| s2 | 這個 skill 把風格寫成一張風格卡：線條多抖、斜線怎麼塗、顏色代表什麼，全部都是參數。改一個數字，整支影片一起變。 | 風格卡參數表；同一個方框三種 roughness 依序畫出 |
| s3 | 每一條線都有固定的種子，逐格渲染不會亂抖，還能一筆一筆畫出來。 | 左 seed＝0 每格都抖；右固定 seed，箭頭一筆一筆畫出 |
| s4 | 你也可以先在 Excalidraw 畫好圖，丟進來，它就照你畫的順序動起來，顏色自動換成風格色。 | .excalidraw 檔案卡 → 光合作用圖逐步畫出 |
| s5 | 照片、圖示和標籤，也會跟著風格走。交付之前，再自動檢查色碼、字級和閱讀時間。 | 照片變拍立得、圖示重畫成手繪線；檢查清單逐項打勾 |
| s6 | 你只要說：幫我做一支手繪風的教學動畫。剩下的，交給這套 skill。 | 拉遠成整張概念圖，中央一張卡寫著那句話 |
