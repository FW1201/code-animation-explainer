# 用 AI 做手寫風教學動畫——這套 skill 怎麼幫你（v3）

> 約 120 秒｜sketch-board（手繪草圖，Excalidraw 式）｜觀眾：會寫一點程式的老師｜旁白以 `storyboard.json` 的 `narration` 為準

| 幕 | 旁白 | 〔畫面〕 |
|---|---|---|
| s0 | 請 AI 做一支手繪風的教學動畫，常常第一幕像是用手畫的，後面幾幕又變回了簡報。 | 一排 5 張幕縮圖，從手繪漸漸變成方正簡報；紅筆圈出走樣的 3 張，問號便利貼 |
| s1 | 因為 AI 每畫一幕，都在重新去猜：手繪風到底是什麼樣子。 | 中央 AI 小頭像想著「手繪風？」，冒出 5 個想法泡泡，每個塗鴉都不一樣 |
| s2 | 這個 skill 給 AI 一張風格卡，就像食譜，寫好線條、顏色和字型。每一幕都照同一張卡畫，整支影片就統一了。 | 左：食譜卡（線條／顏色／字型三欄，各有小樣本）；蓋章「每一幕照這張」；右：5 張縮圖變成同一風格 |
| s3 | 同一份教材，換一張風格卡，就變成黑板、水墨、雜誌，或資料新聞的樣子。內建十六種風格，連照片和圖示都會一起換。 | 同一頁「火箭為什麼飛得上去」依序快切成黑板、水墨、雜誌、資料新聞；再縮成八宮格（8 種風格），便利貼「照片、圖示也一起換」 |
| s4 | 它會一筆一筆把圖畫出來，配好旁白和字幕，還會自動檢查字幕停留夠不夠久，學生來得及讀。 | 左：筆尖帶著畫出水循環小圖；下方字幕條；右：碼表＋三項打勾清單 |
| s5 | 如果你習慣用 Excalidraw 畫圖，也可以直接把圖丟進來，它會照你畫的順序動起來。 | 檔案卡飛進畫面；光合作用圖依原本畫的順序一步步畫出；便利貼「顏色會換成風格色」 |
| s6 | 安裝很簡單：打開終端機，貼上這兩條指令，skill 就會放進 Claude Code 的 skills 資料夾。 | 手繪終端機視窗，兩行指令逐字打出；skill 資料夾沿箭頭放進 ~/.claude/skills/；便利貼「終端機＝打指令的視窗」 |
| s7 | 接著打開 Claude Code，直接說：幫我把這段教材，做成手繪風的教學動畫。 | Claude Code 對話框逐字打出這句話；下方進度清單：選風格 → 配音 → 畫面 → 字幕 → 成片 |
| s8 | 想要真人般的配音，再接上 ElevenLabs 就可以。網址在下面，下載來試試看。 | 拉遠成整張畫布（前面七幕變成一張概念圖），中央 CTA 卡：repo 網址＋兩行安裝指令 |
